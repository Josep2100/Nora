# Claryvo — Producto

## Propuesta de valor

Claryvo ayuda a pequeñas empresas a encontrar información interna y organizar acciones sin tener que buscar manualmente entre múltiples documentos y herramientas.

## Cliente inicial

Empresas de aproximadamente 5–30 personas con muchos procedimientos, preguntas repetitivas o documentación interna, por ejemplo:

- asesorías y gestorías;
- agencias;
- empresas de servicios;
- pequeños despachos;
- consultorías;
- negocios con operaciones administrativas repetitivas.

## Usuario objetivo

El primer comprador debería ser el propietario, gerente o responsable administrativo/operativo de una pequeña empresa.

## MVP

1. Workspace empresarial.
2. Base de conocimiento.
3. Chat contextual.
4. Tareas.
5. Actividad.
6. Configuración básica de empresa.

## Ejemplos de uso

- "¿Qué dice nuestro procedimiento de vacaciones?"
- "¿Qué tareas siguen pendientes?"
- "Resume el procedimiento de atención al cliente."
- "Añade una tarea para revisar el presupuesto el viernes."

Claryvo debe reconocer cuándo no tiene información suficiente y evitar inventar procedimientos.
