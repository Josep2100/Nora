# Checklist de lanzamiento

## Código

- [x] `npm run check` pasa.
- [x] Dashboard Business responsive.
- [x] Endpoints Business implementados.
- [x] README actualizado.
- [x] `.env.example` conservado.
- [x] PWA actualizada.

## Antes de un piloto real

- [ ] Crear Supabase de producción.
- [ ] Configurar secretos en el proveedor de hosting.
- [ ] Probar registro/login/logout.
- [ ] Probar aislamiento entre dos cuentas.
- [ ] Probar exportación y borrado de cuenta.
- [ ] Revisar política de privacidad y términos con profesional.
- [ ] Configurar dominio HTTPS.
- [ ] Definir procedimiento de backups/restauración.
- [ ] Añadir monitorización y alertas.
- [ ] No cargar documentos con secretos o categorías especiales sin una revisión legal y técnica.

## Antes de cobrar

- [ ] Implementar multiusuario real.
- [ ] Implementar RBAC.
- [ ] Implementar facturación.
- [ ] Definir límites de uso y almacenamiento.
- [ ] Definir soporte y SLA.
- [ ] Contratos y DPA cuando corresponda.
